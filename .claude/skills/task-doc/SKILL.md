# Создание BA-постановки задачи (task-doc)

Инструкция целиком лежит в репозитории спеки: **`docs/conventions/prompts/writing/task-statement.md`**.

Прочитать этот файл и выполнить его от начала до конца — Шаг 1 (затронутые части системы) … Шаг 6
(написать файл), затем блок «После записи». Он источник истины; скил — ярлык к нему, своих правил не
добавляет.

Для архитектуры задачи — гайд `task-architecture.md` (скил `task-arch`), для архитектуры фичи —
`feature-architecture.md` (скил `feature-arch`), для имп-дока — `implementation-plan.md` (скил `imp-doc`).

Корень спеки резолвится через `.specs-repo.local` (иначе `.specs-repo`) — в прошивке это `specs/`; все
пути в гайде относительны корню спеки. Если путь не резолвится — остановиться и спросить, не сканируя
соседние репозитории.
